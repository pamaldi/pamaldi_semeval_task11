The core idea

Syllogistic validity is a purely structural property: it depends only on the mood (the AEIO type triple) and the figure (where the middle term sits in each premise) — never on whether the premises are true. LLMs suffer from content effects: they accept invalid-but-plausible arguments and reject valid-but-implausible ones. So the system forbids the LLM from reasoning at all: it emits only four labels and three term strings, and all inference is closed-form lookup.

Note the trade-off: full LLM extraction is slightly more accurate, but the submitted system halves the content effect — and the ranking metric rewards exactly that.

Ranking metric

Score = ACC / (1 + ln(1 + TCE))

TCE (Total Content Effect) measures accuracy gaps across the four validity × plausibility conditions (VP, VI, IP, II). A content-blind system scores the same on plausible and implausible items. The submitted system: 96.34 / (1 + ln(2.02)) = 56.57 — more than double the pure-LLM baseline (26.52) on the same backbone.

Where the residual content effect lives

A branch-level decomposition showed the validator is perfectly content-invariant (it's a set lookup); all residual sensitivity comes from the neural components — the extractor (slightly sensitive to premise ordering) and the LLM fallback. Swapping the extractor backbone (e.g. to Claude Sonnet 4.5) preserves both score and TCE, confirming the symbolic stage is what delivers content-invariance.
